# Matcha Bloom

宇治抹茶と苺の春限定パフェをテーマに制作した、
スマートフォン向けランディングページの制作サンプルです。

## Project Overview

- Project：Matcha Bloom
- Type：Landing Page
- Product：宇治抹茶と苺の春限定パフェ
- Target：20〜30代女性
- Primary CTA：春限定パフェを予約する
- Base Width：390px

## Concept

宇治抹茶のほろ苦さと、
苺のみずみずしい甘酸っぱさを楽しめる、
春限定のご褒美スイーツをテーマに制作しました。

淡いアイボリー、抹茶グリーン、桜ピンクを基調に、
春らしさ・上品さ・親しみやすさを意識しています。
